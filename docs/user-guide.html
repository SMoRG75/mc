Each pane shows one of four places: Local (your PC), DS (data sets and PDS members), USS (z/OS Unix files) or JES (your jobs, with their output as files).

What you need

VS Code

Install Mainframe Commander from the Extensions view, or from the Marketplace.

A Zowe connection

If you already use Zowe Explorer or Zowe CLI, you have one: Mainframe Commander uses the same profiles, passwords and certificates. If not, ask whoever looks after the mainframe how your site connects with Zowe.

For RSE connections only

If your profile is of type rse rather than zosmf, install IBM's RSE plug-in for Zowe once:

zowe plugins install @ibm/rse-api-for-zowe-cli

Both connection types do everything, including TSO commands. Console commands are the one exception: they need a z/OSMF connection.

Getting started

  1. Open Mainframe Commander with Ctrl+Shift+Alt+M (Cmd+Shift+Alt+M on a Mac), or run Mainframe Commander: Open from the Command Palette.
  2. At the top of each pane, pick a connection and a place: Local, DS, USS or JES. Alt+1 to Alt+4 switch between them.
  3. Move with the arrow keys, open with Enter, go up with Backspace, and jump to the other pane with Tab.
  4. Press F1 whenever you forget a key. It lists every shortcut.

The command line

When rows are marked, F5, F6, F8 and F9 work on all of them. With nothing marked, they work on the row under the cursor.

Good to know

  • F5 copies whole folders. A PDS to a folder on your PC, a folder of JCL into a new PDS, or a job's output to disk. Put the two panes on different connections and F5 copies straight from one LPAR to another.
  • The command line (Ctrl+L): tso LISTCAT runs a TSO command, /D T runs a console command as in SDSF, and cd SYS1.PROCLIB jumps straight there. Answers appear in the Output panel. Esc takes you back to the pane.
  • A DS pane starts on your own data sets (YOURUSER.*). Avoid a filter that is just *: it asks the mainframe to walk the whole catalog.
  • When something goes wrong, Mainframe Commander: Show Log shows what happened. It is the thing to attach when you report a problem.

Useful settings

Open VS Code's settings with Ctrl+, and search for Mainframe Commander, or paste the lines below into settings.json via Preferences: Open User Settings (JSON). Replace the profile names and filters with your own.

Where the panes start

// Left pane: your data sets on test
"mc.panes.left":  { "kind": "ds",  "profile": "test", "path": "MYUSER.*" },
// Right pane: your jobs on the same system
"mc.panes.right": { "kind": "jes", "profile": "test", "path": "" }

kind is local, ds, uss or jes; profile is the name of your Zowe connection, and empty means your default one. Normally each pane reopens where you left it; this setting is for forcing a fixed start. Put the two panes on test and prod and F5 copies between the two systems.

What you see first

// A DS pane opens on this filter instead of YOURUSER.*
"mc.ds.defaultFilter": "PROJ.BILLING.*",
// A JES pane shows this user's jobs instead of yours
"mc.jes.owner": "BATCH01",
// How often a JES pane refreshes itself, in seconds (0 = never)
"mc.jes.autoRefreshSeconds": 5

Saved views

The easy way: go to the place and press Ctrl+D. It becomes a ★ tab at the top of the pane. You can also write them yourself, for instance to hand a team the same set:

"mc.favourites": [
  { "name": "My JCL",      "location": { "kind": "ds",  "profile": "prod", "path": "MYUSER.JCL" } },
  { "name": "Billing jobs", "location": { "kind": "jes", "profile": "prod", "path": "owner=BATCH01;prefix=BIL*;status=output" } }
]

Copying with F5

// Your site's EBCDIC code page. The default is IBM-277 (Denmark/Norway);
// IBM-037 is US, IBM-1140 is US with the euro sign, IBM-1047 is Unix-style Latin-1.
"mc.transfer.codepage": "IBM-1140",
// Start copies at once, without the dialog
"mc.transfer.skipDialog": true,
// More file types that always go across as binary
"mc.transfer.binaryExtensions": [".gz", ".zip", ".jar", ".pdf", ".png", ".xlsx", ".docx"],
// A line longer than the data set's record length stops the copy
"mc.transfer.longLines": "abort"
  • Rather than turning the dialog off, you can keep it and press Shift+F5 whenever you want last time's settings without being asked.
  • Leave longLines on abort. truncate cuts the ends off long lines without telling you, which easily breaks JCL; wrap continues the line on the next record.

Everything else

"mc.theme": "neon",          // dark neon look, whatever your VS Code theme
"mc.confirmDelete": true,    // ask before F8; turn off only if you are sure
"mc.list.pageSize": 1000,    // how many rows a listing fetches at a time
"mc.log.level": "info"       // "debug" while chasing a problem
  • Mainframe Commander: Switch Theme flips between the standard look, which follows your VS Code colours, and neon.
  • If a very large folder or library is slow to list, lower mc.list.pageSize and the list comes back sooner.
  • With mc.log.level on debug, the log shows every request to the mainframe and how long it took. It never shows passwords.
