3 · Local pane ↔ mainframe the upload/download variant

Here the left pane is the local disk — same list, same keys. F5 opens the transfer dialog, which is the one place mainframe reality is allowed to show its head: text versus binary, codepage, and which RECFM/LRECL the file lands in. Everything else can be guessed correctly, so the dialog is pre-filled and can be skipped with Shift+F5.

5 · The load-bearing ideas what makes it better than Zowe Explorer

One pane, three worlds

DS / USS / JES are just "file systems" behind the same list. Same keys everywhere — you learn it once.

F5 across LPARs

Left pane LPAR1, right LPAR2. Copy PDS member → USS file, spool → USS, with automatic EBCDIC↔ASCII conversion.

The command line at the bottom

submit, tso, console, cd — typed straight in, starting from the pane's own context.

Background queue

Transfers run in a queue with progress in the status bar. The UI never freezes, even while you fetch an 18 MB tarball.

Virtual list

A PDS with 20,000 members has to scroll as smoothly as one with 20. Only visible rows are rendered.

Quick filter

Just start typing: the list filters live. Ctrl+S as in Total Commander, plus * patterns for dataset names.
